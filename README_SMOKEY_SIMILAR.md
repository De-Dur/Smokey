# Smokey

Interactive browser-based generative artwork for creating soft clouds, smoke, dust, and spores over a live camera background.

## Play the artwork

👉 **[Open Smokey](https://de-dur.github.io/Smokey/)**

## What this project does

Smokey creates soft, evolving particle structures in real time directly in the browser.  
It combines touch interaction, wind, lift, softness, particle density, live camera background, and optional hand tracking into an interactive digital atmosphere.

## Why this project is useful

This project is useful as both:

- a visual art experiment
- a lightweight browser-based artwork for desktop and mobile
- an interactive camera-based generative art tool
- a starting point for experiments with particles, motion, touch, and hand interaction

It allows clouds and atmospheric structures to be created and changed live instead of existing as one fixed rendered image.

## Getting started

1. Open the artwork through the link above.
2. Tap **Camera ON** to allow the live camera background.
3. Use **Touch and Drag** to create and move the particles.
4. Adjust Brush, Amount, Softness, Lift, Wind Direction, and Wind Speed.
5. Switch between Cloud, Smoke, Dust, and Spores.
6. Use **Hand Tracking ON** if you want to control the effect with your hand.
7. Click **Export PNG** or **Export Video** to save the result.

## Help

If the camera or hand tracking does not work correctly:

- open the artwork through the GitHub Pages HTTPS link
- allow camera permission when the browser asks
- use Chrome or Safari
- avoid opening the HTML directly as a `content://` local file on Android
- reopen the page after changing browser permissions
